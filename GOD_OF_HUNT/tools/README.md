# شبیه‌ساز تشخیص (فقط برای توسعه)

این پوشه به متاتریدر ربطی ندارد و نباید در `MQL5/Indicators` کپی شود.

`GOD_OF_HUNT_Core.mqh` را به یک برنامهٔ C++ قابل اجرا تبدیل می‌کند تا بشود منطق
تشخیص را روی کندل‌های ساختگی **اجرا** کرد، به جای اینکه از روی عکس چارت حدس
زده شود. هر بار که قاعده‌ای عوض می‌شود، این را اجرا کنید.

```bash
python3 mksim.py          # sim_core.h را از GOD_OF_HUNT_Core.mqh می‌سازد
g++ -std=c++17 -w -o sim sim.cpp
./sim
```

`mksim.py` نقاط رد شدن `ValidateAB` و باطل شدن `EvaluateLifecycle` را
شماره‌گذاری می‌کند، پس خروجی می‌گوید دقیقاً کدام شرط الگو را رد کرده.

سناریوهای فعلی در `main()` داخل `sim.cpp`:

1. یک `AB` صعودی کاملاً تمیز با اصلاح ۴۰٪
2. همان، ولی با یک لگ مخالف تمیز بعد از آن
3. لگ نزولی که با کندل پین‌بار تمام می‌شود (شکل چارت AUDUSD H4)
4. زیگزاگ ۶ لگی، برای اینکه تعداد تشخیص‌ها منفجر نشود

سناریوی ۴ نگهبان بازگشتی هم دارد: هیچ دو سویینگ پذیرفته‌شده‌ای نباید بیش از
یک کندل چرخش با هم اشتراک داشته باشند.
